# 2026-11-16 · El comando ajeno, cerrado en todas las tablas

- **Qué cambió:** el /chaos de manos libres cerró el comando ajeno solo en `registrar_venta` y `registrar_compra`. El abono, la merma, el gasto, la temperatura y el pago a proveedor se insertan directo, y ventas y compras también aceptan un insert directo: ahí la RLS solo miraba el rol. Además del comando «pendiente», había algo peor: si el ayudante guardaba primero con el comando del dueño, la confirmación del dueño chocaba con «ya guardado» y se daba por buena con el monto del ayudante. La migración `20261117000800_comando_ajeno_en_cada_tabla` pide en la política de inserción del ayudante que el comando, si lo hay, sea suyo (`comando_propio()`), en las siete tablas con `comando_voz_id`. El dueño y el administrador siguen pudiendo todo, y sin comando nada cambia. La app no cambia: el rechazo es 42501 y cada acción ya dice «Tu cuenta no puede…».
